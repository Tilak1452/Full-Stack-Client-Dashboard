🔐 Auth Flow (JWT Lifecycle)
1
Login / Signup — Frontend calls Supabase JS SDK directly. FastAPI is NOT involved at auth time.
2
JWT Issued — Supabase returns a signed JWT (ES256 or HS256 depending on project age) to the browser session.
3
API Calls — api-client.ts calls supabase.auth.getSession() and attaches Authorization: Bearer <jwt>.
4
Backend Verifies — security.py auto-detects HS256 plain string vs ES256 JWK JSON from env var. Decodes and validates.
5
Identity Extracted — sub UUID used as user_id for portfolio/alert row isolation. No local users table exists.

Backend Architecture

Services Layer — All 13 Singletons

Every service is instantiated once at module import time and reused for the process lifetime. Route handlers call services — no business logic lives in the API layer.

stock_service.py
~25KB · Highest-connectivity "god node"

yFinance wrapper with circuit breaker. Core data hub called by routes, agent tools, price update job, and other services.

GETget_current_price(symbol) → price, change, change_pct, market_state, volume
GETget_full_stock_data(symbol) → StockDataResponse (price + RSI/SMA/EMA + fundamentals)
GETget_historical_data(symbol, period, interval) → OHLCV list for charting
GETget_indicators(symbol) → RSI-14, SMA-20, EMA-20 via indicators.py
portfolio_service.py
Portfolio CRUD + FIFO P&L engine

All portfolio mutations. Takes SQLAlchemy Session via get_db() dependency injection. The frontend gets pre-computed P&L values from the background job, not from this service at request time.

BUYrecord_transaction() → weighted avg cost recalculation, new Holding row if needed
SELLrecord_transaction() → FIFO realized P&L computed, holding qty reduced or deleted
GETget_portfolio_summary() → sums cost_basis, current_value, unrealized_pl across all holdings
JOBupdate_holding_prices(db, holding_id, price) → called by APScheduler every 5 min
news_service.py
Yahoo RSS + NewsAPI + VADER Sentiment

Fetches, deduplicates (by URL), and scores financial news headlines. No API key required for the primary Yahoo Finance RSS source.

GETget_news(limit=20) → [{ title, source, url, summary, sentiment }]
VADERcompound > 0.05 → positive · < -0.05 → negative · else neutral
alert_service.py + price_update_job.py
APScheduler-driven background jobs

Two independent background loops running on APScheduler, registered at startup and shut down gracefully on exit.

ALERTEvery 300s — checks price/RSI/SMA vs threshold for all active alerts. Sets status="triggered" + triggered_at on match.
CONDITIONSprice_above · price_below · rsi_above · rsi_below · sma_cross_above · sma_cross_below
PRICE JOBEvery 5 min — batch-fetches all distinct holding symbols via yfinance.Tickers() in one HTTP call. Updates current_price, current_value, unrealized_pl for every holding row.
mpt_service.py
Modern Portfolio Theory optimizer

PyPortfolioOpt-powered Max-Sharpe ratio optimization for the user's existing portfolio holdings.

15 years of adjusted close prices fetched via yFinance
2mean_historical_return() + sample_cov() covariance matrix
3EfficientFrontier().max_sharpe() → cleaned weights + annual return, volatility, Sharpe ratio
MINRequires ≥ 2 symbols. Returns 400 HTTPException otherwise.
macro_service.py · options_service.py
Macro + Derivatives data

Macro data from FRED (with pandas_datareader try/except fallback) and commodity prices from yFinance futures. Options chain + pure Black-Scholes pricer.

MACRO10Y Treasury · CPI · Unemployment (fallbacks: 4.28, 3.2, 3.9) · Gold GC=F · WTI CL=F
OPTIONSNearest-expiry chain via yf.Ticker(symbol).option_chain()
B-Scalculate_black_scholes(S, K, T, r, sigma, option_type) → theoretical price
setup_engine.py · market_structure.py · categorizer.py · data_provider.py
Technical Intelligence + Agent Support Services
setup_engine.py
RSI Recovery (was <30, now rising above 35) · Volume Breakout (2× 20-day avg) · Trend Alignment (price above SMA+EMA, RSI 50–70)
market_structure.py
Trend: uptrend/downtrend/sideways (20d vs 50d SMA) · Support levels (swing lows) · Resistance (swing highs) · 52-week range position
categorizer.py
Classifies query intent: stock_analysis · news · portfolio · macro · general. Used by agent's classify_intent node.
indicators.py
Pure math. No I/O. RSI-14 (Wilder EWMA) · SMA-20 (arithmetic mean) · EMA-20 (multiplier 2/21). Accepts price list, returns float.

⚠️ Known Production Issues & Technical Debt
Macro FRED data frozen
pandas_datareader incompatible with pandas ≥ 3.0. Always falls back to static hardcoded values (Treasury 4.28, CPI 3.2).
Dashboard mock data
Portfolio Value Chart and AI Insights sidebar still use mock.ts static data. Not connected to live APIs.
Watchlist not persisted
Stored in browser localStorage only. Clearing browser data loses the watchlist. No backend /watchlist endpoint exists.
No Alembic migrations
Schema changes require manual ALTER TABLE in migrate.py. create_all() is skipped entirely in production (PgBouncer transaction mode).
